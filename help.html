⚙️ اجرای نصب‌کننده

در مرورگر خود آدرس زیر را باز کنید:

https://yourdomain.com/virus-total-bot/install.php

اطلاعات زیر را در فرم نصب وارد کنید:

  1. توکن ربات - دریافت شده از BotFather
  2. کلید API ویروس توتال - کلید پیش‌فرض یا کلید شخصی شما
  3. کانال اجباری ۱ - مانند @ArteryHub
  4. کانال پشتیبان ۲ - اختیاری
  5. شناسه ادمین - شناسه عددی تلگرام شما
⚠️
هشدار امنیتی:

پس از اتمام نصب، فایل install.php را از هاست خود حذف کنید!

Open the following URL in your browser:

https://yourdomain.com/virus-total-bot/install.php

Fill in the installation form with these details:

  1. Bot Token - Received from BotFather
  2. VirusTotal API Key - Default or your personal key
  3. Required Channel 1 - e.g., @ArteryHub
  4. Backup Channel 2 - Optional
  5. Admin ID - Your Telegram numeric ID
⚠️
Security Warning:

After installation, delete the install.php file from your hosting!
